Tìm kiếm & đếm phép so sánh

Tuyến tính có tận dụng mảng tăng dần, nhị phân — và đếm đúng phép mà đề hỏi.

Thắng lợi của bài: viết tay được hàm tìm kiếm tuyến tính dừng sớm trên mảng tăng dần, và nói ngay số lần so sánh a[i]==x khi x ở đầu / cuối / giữa mảng.

Cho mảng a gồm n số nguyên tăng dần. (a) Viết tìm kiếm tuyến tính có sử dụng điều kiện tăng dần — viết bản thường chỉ được 0.25/0.5đ. (b) Tính số lần so sánh a[i]==x khi x ở đầu, cuối, giữa mảng (chỉ nêu kết quả).

1. Tuyến tính trên mảng tăng dần: dừng khi a[i] > x

Bản thường duyệt đến hết mảng nếu không thấy x. Khi mảng tăng dần, gặp phần tử lớn hơn x là biết chắc phía sau không còn x — dừng luôn. Đó chính là "sử dụng điều kiện tăng dần" mà đề đòi.

int LinearSearch(int a[], int n, int x) {
    for (int i = 0; i < n && a[i] <= x; i++)   // dừng sớm khi a[i] > x
        if (a[i] == x) return i;                // phép so sánh đề hỏi
    return -1;
}

2. Đếm phép so sánh a[i]==x

Mỗi vòng lặp chạy thân đúng một lần ⇒ mỗi phần tử được xét tốn đúng 1 phép a[i]==x. Nếu x nằm ở chỉ số k (đếm từ 0) thì đã xét k+1 phần tử:

Vị trí của xSố lần a[i]==x
Đầu mảng (k = 0)1
Cuối mảng (k = n−1)n
Giữa mảng (k ≈ n/2)≈ n/2  (chính xác: k+1; n lẻ ⇒ (n+1)/2)

Không có x: chỉ các phần tử ≤ x mới bị so sánh == — đó là lợi ích của dừng sớm.Ví dụ a = 2 4 6 8, x = 5: chỉ xét 2 và 4 ⇒ 2 lần ==; gặp 6 > 5 thì vòng for dừng.

Đề đếm một loại phép so sánh. i < n và a[i] <= x cũng là phép so sánh nhưng không tính khi đề ghi rõ a[i]==x. Đọc kỹ đề đếm phép nào trước khi đếm. Câu "giữa mảng" an toàn nhất: ghi kết quả kèm công thức k+1.

3. Nhị phân: mỗi lần so sánh loại nửa mảng

int BinarySearch(int a[], int n, int x) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] == x) return mid;
        if (x < a[mid]) right = mid - 1;   // bỏ nửa phải
        else            left  = mid + 1;   // bỏ nửa trái
    }
    return -1;
}

Điền điều kiện dừng sớm để hàm tận dụng mảng tăng dần:

for (int i = 0; i < n && ; i++)
    if (a[i] == x) return i;
Điều kiện a[i] <= x: còn phần tử ≤ x thì còn hy vọng gặp x; gặp phần tử lớn hơn x là dừng. Dùng a[i] < x là sai — vòng lặp dừng ngay khi a[i] == x mà chưa kịp so sánh.

Kết quả:

Xét 2, 4, 6 (đều ≤ 7) ⇒ 3 lần. Đến 8 > 7 thì điều kiện a[i] <= x sai, vòng lặp dừng, không so sánh == nữa. Bản thường sẽ tốn 6 lần.

Nhị phân trên a = 1 3 5 7 9 11 13, tìm x = 4 (không có). Bao nhiêu lần a[mid]==x?

Kết quả:

mid = 3 (7) ⇒ right = 2; mid = 1 (3) ⇒ left = 2; mid = 2 (5) ⇒ right = 1; left > right dừng. 3 lần = ⌊log₂7⌋ + 1.
