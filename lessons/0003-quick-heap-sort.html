Quick & Heap Sort

Hai thuật toán đếm nhiều điểm nhất: viết tay đúng chuẩn sách, và chạy tay từng bước không sai một ô.

Thắng lợi của bài: viết tay nguyên hai hàm QuickSort (pivot giữa, do-while) và HeapSort (Shift/CreateHeap), và trả lời được kiểu câu "hỏi 1 chi tiết": pivot lần gọi đầu, mảng sau CreateHeap, số lần swap của lần phân hoạch đầu.

(Kiểu câu 3 đề mẫu) Cho mảng a gồm n số nguyên. (a) Điền vào chỗ trống để hàm QuickSort sau chạy đúng; (b) cho biết giá trị pivot ở lần gọi đầu tiên; (c) viết mảng a sau khi kết thúc lần phân hoạch đầu tiên và số lần đổi chỗ (swap) trong lần đó.

1. QuickSort: pivot giữa, do-while — nguyên bản phải thuộc

void QuickSort(int a[], int left, int right) {
    int i = left, j = right, x = a[(left + right) / 2];
    do {
        while (a[i] < x) i++;
        while (a[j] > x) j--;
        if (i <= j) {
            swap(a[i], a[j]);
            i++; j--;
        }
    } while (i < j);
    if (left < j) QuickSort(a, left, j);
    if (i < right) QuickSort(a, i, right);
}

Ghi nhớ cấu trúc: một pivot x lấy ở giữa (left+right)/2; hai con trỏ i chạy phải, j chạy trái; i <= j thì swap rồi cùng bước thêm một nhịp; dừng khi i >= j; đệ quy hai nửa (left, j) và (i, right).

Gọi QuickSort(a, 0, 7): x = a[(0+7)/2] = a[3] = 8. Bảng từng bước (trạng thái mảng sau mỗi lần swap):

Bốn bẫy của câu này: (1) pivot là a[(left+right)/2] — chỉ số nguyên, mảng 8 phần tử (0..7) lấy a[3], không phải a[4]; (2) điều kiện swap là i <= j (có dấu bằng); (3) sau swap phải i++; j--; nếu không vòng lặp quay lại chỗ cũ; (4) sau do-while là while (i < j), còn hai lời gọi đệ quy dùng j (bên trái) và i (bên phải) — đừng hoán đổi.

3. HeapSort: heap cực đại, đếm từ 0

MảngHeap coi node i có con trái 2i+1, con phải 2i+2, cha (i−1)/2. Heap cực đại (max-heap): cha ≥ mọi con ⇒ a[0] là giá trị lớn nhất.

void Shift(int a[], int l, int r) {
    int i = l, j = 2 * i + 1, x = a[i];
    while (j <= r) {
        if (j < r && a[j] < a[j + 1]) j++;   // chọn con lớn hơn
        if (a[j] <= x) break;                   // đúng trật tự thì dừng
        a[i] = a[j]; i = j; j = 2 * i + 1;       // kéo con lên, đi xuống tiếp
    }
    a[i] = x;
}
void CreateHeap(int a[], int n) {
    for (int l = n / 2 - 1; l >= 0; l--) Shift(a, l, n - 1);
}
void HeapSort(int a[], int n) {
    CreateHeap(a, n);
    for (int r = n - 1; r > 0; r--) {
        swap(a[0], a[r]);      // đưa max về cuối
        Shift(a, 0, r - 1);    // vun lại heap trên a[0..r-1]
    }
}

CreateHeap duyệt node cuối lên: từ l = n/2 − 1 (node trong cuối cùng, có con đầu tiên) giảm dần về 0.

Heap đếm từ 0: con là 2i+1 / 2i+2 (bản 1-indexed trong một số sách là 2i / 2i+1 — đề UIT theo bản 0-indexed). CreateHeap bắt đầu ở n/2 − 1 chứ không phải n/2. Trong Shift, so sánh hai con để chọn con lớn hơn trước khi kéo lên. Sau swap(a[0], a[r]) phải Shift trên đoạn 0..r−1, không phải cả mảng.
