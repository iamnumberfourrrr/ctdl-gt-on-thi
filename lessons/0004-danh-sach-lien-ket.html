Bài 04 · ~15 phút · Câu 4 & Câu 9 đề mẫu (2.0đ)

Danh sách liên kết đơn

DSLK đơn với pHead–pTail: thêm, xóa, tìm, duyệt — rồi áp ngay vào cộng hai đa thức.

Thắng lợi của bài: viết tay được add_Y_after_X đúng 4 chỗ trống (không quên cập nhật pTail) và hàm Sum cộng hai đa thức giữ số mũ giảm dần, bỏ hệ số 0 — trọn 2.0đ của Câu 4 + Câu 9.

Câu 4 (1.0đ): điền chỗ trống hoàn chỉnh hàm add_Y_after_X(L, Y, X) thêm phần tử Y sau phần tử X trong DSLK đơn — cho sẵn struct NODE/LIST, searchNode (trả về node chứa X, NULL nếu không thấy) và CreateNode. Trống ở 4 chỗ: lệnh khi Q == NULL, hai lệnh nối p vào sau Q, lệnh cập nhật L.pTail.

1. Khung NODE/LIST và bốn lệnh nền

Mọi câu DSLK của đề đều chạy trên đúng hai struct này. Node giữ dữ liệu + con trỏ pNext; danh sách chỉ cần nhớ node đầu (pHead) và node cuối (pTail) — có pTail thì thêm cuối chỉ tốn O(1), không phải duyệt cả danh sách.Pat Morin, Open Data Structures (bản C++), mục 3.1 SLList: SLList giữ head và tail; thêm vào danh sách rỗng phải đặt cả tail, xóa node cuối cùng phải đặt tail = NULL — đúng quy tắc pHead/pTail bên dưới.

pHead → [2|•] → [6|•] → [5|∅] ← pTail        (∅ = NULL: node cuối)

struct NODE {
    int info;
    NODE* pNext;
};
struct LIST {
    NODE* pHead;
    NODE* pTail;
};
void CreateEmptyList(LIST &L) {
    L.pHead = L.pTail = NULL;
}
NODE* CreateNode(int x) {
    NODE* p = new NODE;
    p->info = x;
    p->pNext = NULL;            // node mới luôn trỏ NULL trước khi nối
    return p;
}
void AddHead(LIST &L, NODE* p) {
    if (L.pHead == NULL) L.pHead = L.pTail = p;   // rỗng: p là đầu lẫn cuối
    else { p->pNext = L.pHead; L.pHead = p; }
}
void AddTail(LIST &L, NODE* p) {
    if (L.pHead == NULL) L.pHead = L.pTail = p;
    else { L.pTail->pNext = p; L.pTail = p; }
}

Mọi hàm thêm/xóa đều rơi vào hai nhánh: danh sách rỗng (pHead và pTail phải đổi cùng nhau) và thao tác chạm đến node đầu/cuối (phải cập nhật đúng một trong hai con trỏ đó). Nhớ hai nhánh này là tự kiểm tra được mọi bài.

2. Duyệt để xử lý theo yêu cầu: một khuôn dùng cho mọi bài

Đề hay cho "duyệt để xử lý theo yêu cầu" — đếm, tính tổng, tìm max, in theo điều kiện. Tất cả dùng chung một khuôn, chỉ thay thân vòng lặp:

int CountNode(LIST L) {
    int d = 0;
    for (NODE* p = L.pHead; p != NULL; p = p->pNext)
        d++;
    return d;
}

Cùng khuôn: tổng (d += p->info;), tìm max (if (p->info > m) m = p->info;), đếm phần tử chẵn (thêm if (p->info % 2 == 0))… Duyệt luôn bắt đầu từ L.pHead và dừng khi p == NULL.

3. Thêm Y sau X — add_Y_after_X (Câu 4)

Tìm X trước (đề cho sẵn searchNode), rồi nối node mới p vào giữa Q và node kế tiếp của Q:

NODE* searchNode(LIST L, int x) {
    for (NODE* p = L.pHead; p != NULL; p = p->pNext)
        if (p->info == x) return p;
    return NULL;
}

void add_Y_after_X(LIST &L, int Y, int X) {
    NODE *Q = searchNode(L, X);       // đề cho sẵn
    if (Q == NULL) return;            // không có X: không chèn, dừng ngay
    NODE* p = CreateNode(Y);
    p->pNext = Q->pNext;              // (1) TRƯỚC: p móc vào node sau Q
    Q->pNext = p;                     // (2) SAU: Q mới móc vào p
    if (L.pTail == Q) L.pTail = p;    // X là node cuối: p thành pTail mới
}
Trước:  ... --> [Q|•-] --> [r|•-] --> ...     p = [Y|•-]--> NULL
                   r là node ngay sau Q        (mới tạo, chưa nối)

(1) p->pNext = Q->pNext;   p móc giữ r trước -- r không bị mất
(2) Q->pNext = p;          Q mới trỏ sang p

Sau:    ... --> [Q|•-] --> [Y|•-] --> [r|•-] --> ...

Đề chấm gắt 3 điểm. (1) if (Q == NULL) phải return; ngay — không có X mà vẫn chạy tiếp thì Q->pNext dereference con trỏ NULL. (2) Hai lệnh nối phải đúng thứ tự: p->pNext = Q->pNext; TRƯỚC, Q->pNext = p; SAU — viết đảo là node Y tự trỏ vào chính nó và mất hết phần sau Q (kiểm bằng mã: sau thứ tự sai, p->pNext == p). (3) X là node cuối thì phải L.pTail = p; — quên là pTail vẫn trỏ node cũ, mọi AddTail sau đó gắn sai chỗ.

4. Xóa node: RemoveHead và RemoveX (giữ prev, cập nhật pTail)

Xóa đầu thì dời pHead; xóa một node bất kỳ thì phải nhớ node đứng trước nó (prev) để nối tắt qua node bị xóa:

Xóa node p (node trước là prev):
Trước:  [prev|•-] --> [p|•-] --> [r|•-]
Sau:    [prev|•-] ---------------> [r|•-]     prev->pNext = p->pNext; delete p;

void RemoveHead(LIST &L) {
    if (L.pHead == NULL) return;            // rỗng: hết việc
    NODE* p = L.pHead;
    L.pHead = p->pNext;
    delete p;
    if (L.pHead == NULL) L.pTail = NULL;    // vừa xóa node duy nhất
}

bool RemoveX(LIST &L, int x) {
    NODE *prev = NULL, *p = L.pHead;
    while (p != NULL && p->info != x) {     // tìm x, nhớ node trước
        prev = p;
        p = p->pNext;
    }
    if (p == NULL) return false;            // không có x
    if (prev == NULL) L.pHead = p->pNext;   // x ngay đầu: dời pHead
    else prev->pNext = p->pNext;            // nhảy qua node p
    if (p == L.pTail) L.pTail = prev;       // x là node cuối: pTail lùi về prev
    delete p;
    return true;
}

Ba trường hợp đặc biệt luôn phải nghĩ đến: x ở đầu (prev == NULL), x ở cuối (L.pTail = prev), và x là node duy nhất (cả hai: pHead về NULL, pTail về NULL).

5. Câu 9 — đa thức bằng DSLK: DATHUC, Input, Sum

Câu 9 (1.0đ, tự luận): lưu đa thức thưa một biến bằng DSLK đơn, mỗi node một đơn thức (HeSo, SoMu), số mũ giảm dần — ví dụ P(x) = 100x⁷⁰ + 25x¹⁵ − 6x³ + 9. Cho sẵn CreateNode, AddTail, CreateEmptyDATHUC, Input(heso, somu), Output. a) Định nghĩa DATHUC (0.25đ); b) Input(DATHUC&) — nhập số lượng, rồi từng hệ số–số mũ (0.25đ); c) Sum cộng hai đa thức, trả về đa thức mới cũng giảm dần, không chứa đơn thức hệ số 0 (0.5đ).

a) Chỉ khác bài thường ở kiểu dữ liệu của node — vẫn pHead/pTail:

struct DONTHUC {
    float HeSo;
    int SoMu;
};
struct NODE {
    DONTHUC info;
    NODE* pNext;
};
struct DATHUC {          // câu a: trả lời đúng 1 dòng struct này
    NODE* pHead;
    NODE* pTail;
};

b) Input: đếm n rồi AddTail từng đơn thức — đề quy ước nhập theo số mũ giảm dần, nên AddTail giữ nguyên thứ tự đó:

void Input(DATHUC &poly) {
    CreateEmptyDATHUC(poly);
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        float hs; int sm;
        cin >> hs >> sm;
        AddTail(poly, CreateNode(Input(hs, sm)));
    }
}

c) Sum: trộn hai danh sách đã giảm dần — như cộng hai dãy đã sắp xếp: so sánh số mũ của node đang xét mỗi bên, lấy bên lớn hơn; bằng nhau thì cộng hệ số; còn sót bên nào thì AddTail nốt. Nhánh "bằng nhau" là chỗ đề chấm: tổng hệ số bằng 0 thì không thêm node nào.

DATHUC Sum(DATHUC poly1, DATHUC poly2) {
    DATHUC kq; CreateEmptyDATHUC(kq);
    NODE *p = poly1.pHead, *q = poly2.pHead;
    while (p && q) {
        if (p->info.SoMu > q->info.SoMu) {          // bên lớn hơn thắng
            AddTail(kq, CreateNode(p->info));
            p = p->pNext;
        }
        else if (p->info.SoMu < q->info.SoMu) {
            AddTail(kq, CreateNode(q->info));
            q = q->pNext;
        }
        else {                                       // số mũ bằng nhau
            float hs = p->info.HeSo + q->info.HeSo;
            if (hs != 0)                             // hệ số 0: bỏ luôn
                AddTail(kq, CreateNode(Input(hs, p->info.SoMu)));
            p = p->pNext;
            q = q->pNext;
        }
    }
    for (; p; p = p->pNext) AddTail(kq, CreateNode(p->info));
    for (; q; q = q->pNext) AddTail(kq, CreateNode(q->info));
    return kq;
}

Chạy tay (đã kiểm bằng mã): poly1 = 5x³ + 2x + 1, poly2 = −5x³ + 4x:

bướcp (poly1)q (poly2)số mũhành độngkq
15x³−5x³3 = 3hs = 5 + (−5) = 0 → bỏ(rỗng)
22x¹4x¹1 = 1hs = 6 → thêm6x¹
31x⁰NULL—q hết → AddTail nốt p6x¹ 1x⁰

Kết quả: Sum = 6x + 1 — số hạng x³ biến mất vì hệ số 0.

Ba lỗi mất điểm Câu 9: (1) vẫn in đơn thức hệ số 0 — 5x³ + (−5x³) phải bỏ, không được ghi 0x³; (2) làm mất thứ tự số mũ giảm dần — trộn hai danh sách đã giảm dần thì tự ra kết quả giảm dần, chỉ dùng AddTail, đừng AddHead; (3) ghi đắp lên poly1/poly2 — đề đòi đa thức mới, vậy cứ CreateNode node mới (như code trên), không tái dùng node cũ.

Danh sách L đang là 2 6 5 (pHead → 2, pTail → 5). Gọi add_Y_after_X(L, 8, 5). Danh sách in ra và pTail->info sau lời gọi?

Danh sách:   pTail->info:

X = 5 chính là node cuối ⇒ node 8 mới chèn thành node cuối: phải có L.pTail = p. Danh sách 2 6 5 8, pTail->info = 8. Trả lời 5 là quên cập nhật pTail.

Tiếp đoạn trên (danh sách 2 6 5 8): gọi RemoveHead(L) rồi RemoveX(L, 8). Danh sách và pTail->info?

Danh sách:   pTail->info:

RemoveHead bỏ node 2 ⇒ 6 5 8. RemoveX(8) xóa node cuối: prev là node 5, nên L.pTail = prev ⇒ pTail->info = 5, còn 6 5.

Danh sách 1 2 3 4, chèn 9 sau node 2 nhưng viết đảo thứ tự: Q->pNext = p; trước, p->pNext = Q->pNext; sau. Khi đó p->pNext trỏ tới:

Lệnh 1 cho Q->pNext = p (node 3, 4 rớt khỏi chuỗi). Lệnh 2 đọc lại Q->pNext — giờ đã là p — nên p->pNext = p: node 9 tự trỏ vào chính nó, duyệt tới đây là lặp vô hạn. Kiểm bằng mã: sau thứ tự sai, p->pNext == p.

Viết ra giấy hàm int CountEven(LIST L) đếm số node có info chẵn. Với danh sách 2 7 4 9 6 5 hàm trả về bao nhiêu?

int CountEven(LIST L) {
    int d = 0;
    for (NODE* p = L.pHead; p != NULL; p = p->pNext)
        if (p->info % 2 == 0)
            d++;
    return d;
}
