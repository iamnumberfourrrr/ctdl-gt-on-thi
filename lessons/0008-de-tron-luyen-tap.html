Bài 08 · ~25 phút · Đề mô phỏng 10 câu (10.0đ)

Đề trộn — luyện tập tổng hợp

Đủ 10 câu đúng cấu trúc đề mẫu, nhưng dữ liệu mới và chủ đề bị trộn thứ tự — kiểm tra xem kiến thức có "bám" được chưa.

Thắng lợi của bài: làm trọn một đề 10 câu trên giấy trong ~25 phút (bản thu nhỏ của 90 phút thật), tự chấm từng câu, và biết chính xác câu nào phải quay lại bài nào.

Đề mẫu ghi: "Sinh viên không được sử dụng tài liệu, Làm bài trên đề" — 90 phút, 2 phần: Câu trả lời ngắn (câu 1–8) + Câu hỏi tự luận (câu 9–10), tổng 10 câu. Đề mô phỏng bên dưới giữ nguyên cấu trúc và thang điểm đó, chỉ đổi dữ liệu và trộn thứ tự chủ đề.

Cách làm đề này

  1. Bấm giờ ~25 phút, làm toàn bộ 10 câu ra giấy — không lướt bài trước, không mở code mẫu.
  2. Làm xong mới bấm Hiện đáp án / Hiện lời giải của từng câu để tự chấm; câu vẽ thì so với hình trong lời giải.
  3. Câu sai → bấm link Ôn lại cuối câu, quay về đúng bài dạy kỹ năng đó; hôm sau làm lại đề này cho trôi.

b. (0.5đ) Số lần so sánh a[mid]==x: x = 25 → · x = 5 (không có) → · x = 16 →

b. x = 25: mid=5 (16<25) → mid=8 (25) ⇒ 2 lần. x = 5: mid=5 (16) → mid=2 (7) → mid=0 (2) → mid=1 (4), left>right dừng ⇒ 4 lần = ⌊log₂12⌋+1. x = 16 nằm đúng mid đầu tiên ⇒ 1 lần (tốt nhất).

int BinarySearch(int a[], int n, int x) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}

Xấu nhất ⌊log₂n⌋ + 1 lần so sánh.Wikipedia — Binary search, Performance.

Phần 2 — Tự luận (câu 9–10)

Câu 9 (1.0đ) — Viết hàm void RemoveAllNegative(LIST &L) xóa mọi node có info < 0 khỏi DSLK đơn, giữ nguyên thứ tự phần còn lại, cập nhật đúng pHead, pTail.

Xóa ở đầu bằng vòng lặp (vì có thể nhiều node âm liền nhau), rồi giữ node trước để nối cúi khi gặp node âm ở giữa/cuối:

void RemoveHead(LIST &L) {
    if (L.pHead == NULL) return;
    NODE *p = L.pHead;
    L.pHead = p->pNext;
    delete p;
    if (L.pHead == NULL) L.pTail = NULL;   // danh sách rỗng sau khi xóa
}

void RemoveAllNegative(LIST &L) {
    while (L.pHead != NULL && L.pHead->info < 0)   // xóa ở đầu
        RemoveHead(L);
    if (L.pHead == NULL) return;                       // rỗng hết
    NODE *prev = L.pHead;
    while (prev->pNext != NULL) {
        NODE *p = prev->pNext;
        if (p->info < 0) {
            prev->pNext = p->pNext;
            if (p == L.pTail) L.pTail = prev;          // xóa node cuối
            delete p;
        }
        else prev = p;                                 // chỉ tiến khi không xóa
    }
}

Biên dịch chạy thử: −3 5 −2 −7 8 −4 9 → 5 8 9 (tail = 9); danh sách toàn số âm (−1 −2 −3) → rỗng, pTail = NULL. Sinh viên chỉ viết được phần giữa mà quên vòng xóa đầu, hoặc quên cập nhật pTail, là mất nửa số điểm.

Câu 10 (0.5đ) — Cho TNODE{key, pLeft, pRight}. Viết hàm đệ quy int CountOneChild(TREE T) đếm số node có đúng một con trong BST.

int CountOneChild(TREE T) {
    if (T == NULL) return 0;
    int self = 0;
    if ((T->pLeft == NULL) != (T->pRight == NULL)) self = 1;
    return self + CountOneChild(T->pLeft) + CountOneChild(T->pRight);
}

Điều kiện "đúng một con" = (pLeft == NULL) != (pRight == NULL) — một bên rỗng, một bên không. Biên dịch chạy thử trên đúng cây T1 của câu 1: các node 10, 30, 80 mỗi node có một con ⇒ kết quả 3.
